Geusaie — ระหว่างที่เส้นพาสต้ากำลังต้ม ซอสก็เสร็จไปด้วย

ติดต่อเรา

ติดขัดตรงไหน เจออะไรแปลก ๆ หรืออยากให้เพิ่มสูตร บอกเราได้เลย

อีเมล leeo@kakao.com · การตั้งค่า ▸ ส่งความคิดเห็น ในแอป · GitHub Issue

ปกติเราตอบกลับภายในไม่กี่วัน ถ้าระบุรุ่นเครื่องและเวอร์ชัน iOS มาด้วยจะเร็วขึ้น

คำถามที่พบบ่อย

พูดว่า “다음” แล้วไม่ไปขั้นตอนถัดไป

ตรวจสอบว่าปุ่มไมโครโฟนที่มุมซ้ายล่างเป็นสีเขียว สีเทาแปลว่าปิดอยู่ เมื่อเปิดครั้งแรกต้องอนุญาตทั้งไมโครโฟนและการรู้จำเสียงพูด หากเคยปฏิเสธ สามารถเปิดใหม่ได้ที่แอปการตั้งค่า ▸ Geusaie ระบบรู้จำเฉพาะคำภาษาเกาหลี “다음” (“ถัดไป”) และอาจรู้จำได้ยากในที่เสียงดังมาก ในกรณีนั้นให้แตะปุ่มถัดไปด้านล่าง

หม้อเสร็จแล้วแต่ไม่มีการแจ้งเตือน

ตรวจสอบว่าเปิดการแจ้งเตือนไว้ที่ การตั้งค่า ▸ การแจ้งเตือน ▸ Geusaie โฟกัสอาจปิดเสียงได้ การแจ้งเตือนจะมาเฉพาะเมื่อหม้อเสร็จ งานเตรียม (หั่น ขูด) ไม่แจ้งเตือน เพื่อไม่ให้รู้สึกถูกเร่ง

ถ้าเริ่มช้า ตารางเวลาจะเป็นอย่างไร

ระบบจะคำนวณใหม่จากเวลาที่คุณทำจริง ถ้าเปิดไฟช้าไป 3 นาที งานถัดไปก็เลื่อนไป 3 นาทีด้วย และซอสจะถูกวางแผนย้อนกลับจากเวลาที่เส้นเสร็จ หากเลยกำหนดของงานที่มีเส้นตาย (เช่น ตักเส้นขึ้น) แอปจะแจ้งว่าช้าแล้ว

ตัวอักษรเล็กเกินไป

ในหน้าจอทำอาหาร แตะปุ่ม aA ที่มุมขวาบน แล้วเลือกปกติ ใหญ่ ใหญ่ขึ้น หรือใหญ่สุด ระบบจะจำที่เลือกไว้

หน้าจอจะดับระหว่างทำอาหารไหม

ไม่ดับ หน้าจอจะติดอยู่ตลอดระหว่างทำอาหาร เราออกแบบให้ไม่ต้องแตะหน้าจอแม้มือเปียก

ขอเพิ่มสูตรอีก
