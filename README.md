# 그사이에 — iOS

> 면 삶는 그사이에 소스까지.
> 냄비 두 개가 서로 다른 속도로 도는 요리를, 한 사람이 놓치지 않고 해내기 위한 타이머.

- **소개 페이지**: https://m1zz.github.io/geusaie/
- **지원 페이지**: https://m1zz.github.io/geusaie/support.html
- **개인정보 처리방침**: https://m1zz.github.io/geusaie/privacy.html

## 이 앱의 전제

요리가 어려운 건 손이 느려서가 아니라, **시간이 한 줄이 아니기** 때문입니다.
면은 사람을 기다려 주지 않고, 마늘 써는 일은 언제 해도 됩니다.
그래서 모든 일을 셋으로 나눕니다.

| 종류 | 예 | 성질 |
|------|-----|------|
| `.prep` 도마 일 | 마늘 썰기, 치즈 갈기, 계량 | **밀려도 된다.** 손이 빌 때만 진행량이 쌓이고, 끊기면 이어서 |
| `.action` 내 동작 | 물 올리기, 면 넣기, 면 건지기, 볶기 | 손이 붙잡힌다. `deadline`이면 **미루면 음식이 상한다** |
| `.cook` 냄비 시간 | 물 끓이기, 면 삶기, 크림 졸이기 | 내가 시작 동작을 해야 돌고, **한번 돌면 안 기다린다** |

레시피에는 **절대 시각이 없습니다.** '무엇 다음에 무엇'만 적혀 있고,
실제로 내가 언제 했는지에서 시간표(`Plan`)를 매번 계산합니다.
불을 3분 늦게 켜면 뒤가 함께 3분 밀리고, 소스는 `.endingWith("면 건지기")`로
**면이 나오는 시각에서 거꾸로** 시작 시점이 잡힙니다.

## 화면

| 화면 | 내용 |
|------|------|
| **홈** | 고를 때 필요한 것만 — 이름, 약 몇 분, 냄비 몇 개 |
| **시작 전** | 첫 할 일을 보여 주고 `요리 시작`을 기다린다. 누르는 순간부터 냄비 시계가 돈다 |
| **조리 중** | 지금 할 일(내 손) · 냄비 두 칸 · 전체 타임라인 |

- **색이 곧 급한 정도** — 초록(천천히) · 머스터드(지금) · 테라코타(못 미룸) · 벽돌(늦음)
- **내 손 일에는 초를 세지 않는다** — 막대가 차오르다 멈추고 기다린다
- **냄비 칸에서는 시간을 숨기지 않는다** — 네모가 줄어드는 만큼이 남은 시간
- **말로 넘기기** — 손이 젖어 있으면 "다음" 한 마디 (`ko-KR`, 가능하면 온디바이스)
- **글자 크기 4단계** — 조리대에 세워 두고 한두 걸음 떨어져 보는 거리 기준

## 실행

1. Xcode 15 이상 (iOS 17 SDK)
2. `Geusaie.xcodeproj` 열기 → Signing & Capabilities에서 팀 선택
3. ⌘R

스크린샷·디버그용 실행 인자 (DEBUG 전용):

```
-demoRecipe aglio-olio     # 그 레시피를 열고 시작 전 화면으로
-demoAt 470                # 470초가 지난 시점부터 (생략하면 시작 전)
-textScale 0~3             # 보통 / 크게 / 더 크게 / 아주 크게
```

## 파일

```
Geusaie/
├── GeusaieApp.swift      # 진입점
├── Theme.swift           # 팔레트, 시간 포맷, 글자 크기 단계
├── Models.swift          # RecipeStep / Recipe / CookState / Plan(시간표 계산)
├── Recipes.swift         # 레시피 DB (분량·요령·완료 신호 포함)
├── CookSession.swift     # 엔진: 냄비 사슬, 도마 일 적립, 알림
├── VoiceCue.swift        # "다음" 음성 인식
├── RecipeListView.swift  # 홈
└── CookView.swift        # 조리 화면 (할 일 카드 · 냄비 칸 · 타임라인)
```
